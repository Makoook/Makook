## 🚀 Vision

Makook is building the future of local errands.

Our mission is to simplify everyday tasks by creating an intelligent platform that connects customers with trusted runners through automation, AI, and efficient operations.

We are not building a delivery application.

We are building an operating system for local errands.

# Core Products

Makook consists of multiple integrated products.

## Customer App

Mobile application for customers.

Main features:

- Create errands
- Track progress
- Chat with runner
- Secure payment
- Order history

---

## Runner App

Mobile application for runners.

Main features:

- Accept errands
- Navigation
- Shopping workflow
- Upload receipts
- Earnings dashboard

---

## Admin Dashboard

Internal management portal.

Features include:

- User management
- Runner management
- Mission monitoring
- Customer support
- Reports

---

## Operations Dashboard

Internal operational platform responsible for:

- Dispatch
- Incident management
- Manual interventions
- Performance monitoring

# Documentation First Development

Makook follows Documentation First Development.

Every feature follows this lifecycle:

```
Idea

↓

Documentation

↓

Architecture

↓

Database

↓

API

↓

UI

↓

Development

↓

Testing

↓

Release
```

No feature is implemented before documentation is approved.
